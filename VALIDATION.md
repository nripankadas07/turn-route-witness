# Validation

100 fixed-seed graphs checked against exhaustive edge-state path enumeration, incoming-state counterexample, unreachable/identity route, zero cycle, invalid turns and negative-cost rejection.

Local behavior, compilation, wheel and clean installed-console evidence will be recorded in PREPARATION.json before publication. Remote CI verifies the actual public branch separately; existence of a repository alone does not imply a verified launch. Inputs are invented. No production corpus, Windows/macOS or fair equivalent competitor benchmark was run. No universal safety/correctness or future-vulnerability guarantee.
