# turn-route-witness

Find minimum integer-cost routes over incoming-edge states with exact forbidden consecutive-edge pairs and compare an unrestricted baseline.

For routing developers reproducing a turn-restriction bug on a small extracted directed graph.

## Quickstart

Linux/Python3.10+; public source installation, no external service or runtime dependencies.

```sh
git clone https://github.com/nripankadas07/turn-route-witness.git
cd turn-route-witness
python -m venv .venv
. .venv/bin/activate
python -m pip install .
turn-route-witness example.json
```

The command prints deterministic JSON. Invented example takes ad,db,bc at cost4 instead of the blocked cost2 ab,bc route. A legal zero-cost loop can change the incoming edge and permit an exit.

All input examples are invented. The tool reads one UTF-8 JSON file, at most1MiB, rejects duplicate keys/nonfinite numbers/unknown fields and never modifies the input. Exit0 means a completed nonfinding result; exit1 means a documented finding (infeasible deadline, unexpected deadlock, no route or failed inclusion). SQL reports all row outcomes with exit0. Exit2 means malformed/unsupported input with stderr and no partial report. Petri exit3 means incomplete exploration with no deadlock found; a found deadlock uses exit1 even if exploration is incomplete.

## Input and interpretation

Start with the exact structure in [example.json](example.json). [Expected JSON](example-output.json) is generated by the validated example.

Normalized directed graph only; at most200 nodes/1000 edges/5000 distinct forbidden pairs; edge costs0..10^9. Pair IDs must refer to consecutive edges. No OSM/coordinates/geocoding, multi-edge/conditional/only-turn restrictions, travel-time prediction, turn penalties or vehicle safety instructions. All unlisted pairs including U-turns are allowed. Zero-cost loops are permitted. Ties deterministic for fixed IDs; no claim of globally lexicographically smallest route. Unreachable is a finding, not malformed input.

Identifiers are nonempty strings up to80 characters. Integer bounds exclude booleans. Required keys and types are validated. These are model diagnostics, not automatic changes to a live system. The report describes supplied data only.

100 fixed-seed graphs checked against exhaustive edge-state path enumeration, incoming-state counterexample, unreachable/identity route, zero cycle, invalid turns and negative-cost rejection.

Linux CI exercises Python3.10/3.12/3.14, wheel installation and the real installed console command from a temporary directory. [Validation details](VALIDATION.md) distinguish local and remote evidence. Windows/macOS and production data are untested.

## Why this small tool

Keeping only the cheapest arrival at a junction can discard the incoming edge needed to take a legal next turn.

gpx-dwell-report analyzes recorded motion, redirect-graph checks web redirects and capacity-cut-report solves allocation flow. This is a route feasibility/cost witness for incoming-edge restrictions, not a map service.
